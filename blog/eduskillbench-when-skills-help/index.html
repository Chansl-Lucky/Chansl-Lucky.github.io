EduSkillBench: When Do Skills Actually Help?

Reusable instructions promise more capable agents. EduSkillBench asks when that promise survives a controlled comparison.

Shilian ChenNovember 5, 20262 min read

On this page

  1. Make the contribution of a skill visible
  2. Ask where a skill helps
  3. From a skill library to evidence

A reusable skill is a compelling promise: package a useful procedure once, then let an agent apply it across tasks. The research question is what happens after the package is loaded. Does the agent make better decisions, or simply produce an answer that looks more structured?

Make the contribution of a skill visible

In EduSkillBench, we study that question through paired evaluations with and without skill guidance. We bring together publicly available educational skills, tasks aligned with their intended use, and explicit scoring rubrics. The comparison makes the contribution of the added guidance visible within a specified evaluation setting.

Education gives this question a concrete form. A useful hint, for example, needs to support the learner's next step; providing the final answer immediately may defeat its purpose. Procedures matter alongside factual correctness. The earlier v1 preprint develops this motivation and describes the initial evaluation.

Ask where a skill helps

A benchmark should help us distinguish useful guidance from guidance that is redundant, poorly matched, or unnecessarily restrictive. I want evaluations to make those differences legible: which tasks benefit, which criteria change, and where a procedure adds unnecessary constraints. An aggregate score is a starting point for understanding those differences. The important next step is to examine the behavior behind it.

The question I find most interesting is whether a procedure remains useful when the situation changes. That is the standard I would want for reusable agent expertise: a skill earns its place through the decisions it improves, and its boundaries should be understandable.

From a skill library to evidence

For our broader work on continually improving agents, this is a useful evaluation mindset. Before accumulating more procedures, we need ways to examine their value. EduSkillBench offers a concrete setting for doing so.

For maintained materials, visit the project repository. The August 2026 preprint documents an earlier version; its setup and results should be read in that version's scope.
